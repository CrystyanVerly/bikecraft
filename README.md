# 🚲 Bikcraft

A responsive website for a fictional bicycle company, focused on modern design, usability, and responsive layouts.

This project is a **refactored and Vite-migrated version** of the Bikcraft website originally developed during the **HTML and CSS course at Origamid**.

The original project was restructured and adapted to a modern development workflow using **Vite**, while preserving the original visual identity and functionality.

## 🔄 Refactoring & Migration

This version goes beyond the original course implementation.

The project was **refactored and migrated from its original structure to Vite**, providing a more modern and organized development environment.

### Main changes

- Migrated the project to **Vite**
- Reorganized the project structure
- Added a modern development workflow with `npm`
- Updated the development and build process
- Refactored existing code where necessary
- Configured the project for production deployment with **Vercel**
- Preserved the original design and core functionality

The goal was to take an existing front-end project and adapt it to a more modern development workflow while maintaining its original purpose and visual identity.

## ⚙️ Getting Started

### Prerequisites

Make sure you have **Node.js** installed on your machine.

### Installation

Clone the repository:

```bash
git clone https://github.com/CrystyanVerly/bikcraft.git
```

Navigate into the project:

```bash
cd bikcraft
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will start the local development server and provide a URL in the terminal, usually:

```text
http://localhost:5173
```

### Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
